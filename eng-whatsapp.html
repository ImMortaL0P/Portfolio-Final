WhatsApp Command Center (AI Chief of Staff)

A premium Operations Command Center application that sits directly on top of WhatsApp (via a local Baileys connection and SQLite database) to act as an AI Chief of Staff. Engineered to bring order to messy communications—especially B-School and MBA preparation groups—it translates chaotic chat logs into structured summaries, tasks, and deadlines.

Key Features & Architecture

Smart Chat Navigator: Synchronized with the live WhatsApp database, it categorizes chats by priority (B-School Threads vs DMs vs General). It computes live AI Priority Scores (10-99) and flags deadline risks, unread counts, and mentions in real-time.

AI Intelligence Feed: Features an Executive Summary of the last 24 hours, a Mention Radar, and an AI Task Engine that auto-extracts checklist tasks into P1 Critical, P2 Important, and P3 Optional matrices.

Gemini AI Terminal

The dashboard includes an interactive command terminal supporting real-time database queries and Gemini AI assistance. Users can issue commands like > summarize group_name, > extract all deadlines, or > draft response to contact. It seamlessly bridges real-time messaging with LLM-powered context generation.

Analytics & Tech Stack

Built with a React/Vite frontend and an Express Node.js backend. The UI is inspired by Notion and Bloomberg Terminal, featuring a default dark mode with tactical crimson red accents, Activity Heatmaps, Response Analytics, and a B-School Relationship graph.
